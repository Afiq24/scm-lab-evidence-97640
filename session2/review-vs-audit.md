# Code Review vs. Formal Configuration Audit
**Name:** Norman Yusoff (97640)

A code review is an informal, ongoing peer check of a single proposed change—such as my pull request (#2) for adding `session2/traceability-note.md`—to catch errors and improve quality before merging. In contrast, a formal configuration audit is a planned, independent verification conducted before a major release or baseline. Specifically, a Functional Configuration Audit (FCA) verifies that the software meets its functional requirements, while a Physical Configuration Audit (PCA) confirms that the built product matches its technical documentation.
